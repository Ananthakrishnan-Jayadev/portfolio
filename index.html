Banking clientGenpact, 2026

QA Automation Hub

An internal platform for a bank's data-engineering QA team. From a vendor's data extract it produces the spec page, the six JIRA stories, the Xray test cases and the schema-validation evidence that used to be written by hand for every data feed.

Chained LLM sub-agents
4
JIRA stories per feed
6
Test verdicts left to a model
0
  • Flask
  • LangGraph
  • OpenAI
  • Databricks
  • SQL Server
  • JIRA / Xray APIs
  • Arize Phoenix
How it works
  • Deterministic first. Spec and ticket generation run on rules, not models. AI only fills blank descriptions and classifications and writes report prose a human reviews; it never counts and never decides PASS/FAIL.
  • Four chained sub-agents (a witness that reports only what it sees, a describer, a PII/PCI classifier that cites evidence, and a summarizer) with closed-set, schema-validated outputs, a circuit breaker and a JSONL audit log for every call.
  • Schema validation stores the expected schema in SQL Server, drives Databricks notebooks against Delta tables in each data zone, and posts PASS/FAIL with an HTML evidence report to Xray.
  • A LangGraph code-generation agent turns a Confluence epic into schema JSON, registration SQL and an ADF trigger, then publishes to a Bitbucket feature branch behind two human approval gates.
  • Dry-run mode on every external write, per-row error tolerance, encrypted access tokens, and air-gapped local tracing with Arize Phoenix.

How it works
  • Seven specialized agents, each grading one group of metrics (pigmentation; redness and acne; facial lines; pores and texture) through the same multimodal pipeline: detect image modality, fill the prompt, call the model, parse JSON, score MAE, MSE and RMSE.
  • One interface over GPT-5.4, Gemini 3.1 Pro, local Ollama models (Gemma 3, Ministral 3, Qwen 3.5) and NVIDIA Cosmos Reason2 self-hosted in a Docker NIM container.
  • Prompts with calibrated scales, anchor examples and strict JSON contracts, cross-checking image overlays before flagging conditions like active acne.
  • GPT-5.4 was the strongest generalist, with 16.5% lower total error than the runner-up. Cosmos ranked last overall yet won 8 of 14 individual metrics, so the recommendation assigns models per metric rather than crowning one leaderboard winner.
